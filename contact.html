How to reach us

The simplest way to contact the project is through the public issue tracker of the site's GitHub repository: GitHub issues for Tractor Wala Game. Please do not post personal or sensitive information in a public issue.

What we cannot help with

We are not the developer of any game and cannot provide technical support for a specific app. For game problems, use the support contact on the official store listing. For general advice, read Tractor Game Troubleshooting.
